RELEASE ITEMS

1. RESOLVED - R35 status pull-up corrected and verified in current files.
   Both schematic netlist and PCB show R35 pin1 on+3V3, with pin2 on the
   U10 ST / U6 IO1 status net. Value remains10kohm. The previous5V pull-up issue is closed.

2. MANUFACTURING - J4 USB NPTH-to-copper spacing remains about0.1944 mm.
   The project rule is0.25 mm and JLC publishes0.2 mm. This is about6 um below the
   published capability. Ask CAM to confirm or adjust the footprint locally; avoid globally
   relaxing clearance. This is an existing standard-footprint geometry issue, not a new artwork fault.
   https://jlcpcb.com/capabilities/Capabilities

3. ASSEMBLY - USB J4 shell stakes require a soldering-process check.
   USB4105-GF-A is correctly SMT-attributed but has four plated through-hole shell slots
   without F.Paste apertures. Ensure the assembler solders these stakes, or finish them manually.
   SMT signal-pad reflow alone should not be assumed to secure all shell anchors.
   https://gct.co/connector/usb4105

4. PROCUREMENT - Add/select J1 inlet fuse cartridges outside the PCB BOM.
   PF0030/PC is a twin-fused5x20 mm inlet; the inlet body does not define the fitted cartridges.
   F1 protects only the IRM-05-5 supply branch. Specify fuse ratings/characteristics for the
   intended load and inlet. The J1/P1 connector rating is10 A/250VAC continuous; 50 A is a
   measurement transient target and does not increase their continuous current rating.
   https://www.bulgin.com/products/media/bulgin/data/IEC_connectors.pdf

SPI AND FIRMWARE

- All12 ADC interface signals are connected. Two separate SPI peripheral buses remain feasible.
- In2 ground covers the bottom SPI runs including SDI escapes, is stitched, and reaches the
  ADC ground vias. The relocated3.3 V feed no longer cuts that reference region.
- Dual-SDO requires deliberate driver/pin routing. ESP DIO data0 is SPI_D/MOSI and data1 is
  SPI_Q/MISO; the board has separate ADC SDI and SDO0 pins. A default ordinary SPI bus
  configuration will not automatically capture both data lanes correctly.
- A feasible approach is startup configuration via ordinary SPI/bit-bang, then separate SDI held
  low for NOPs and read-only DIO on SDO0/SDO1. Alternatively route SPI_D input and output
  independently using the GPIO matrix. Keep ADC SDO GPIOs input-only; do not drive commands
  into an ADC output. This is firmware work, not evidence that another PCB circuit is required.
- Sustained sample rate, clock/sample timing margin, simultaneous-channel skew and lane bit order
  remain to be established in firmware and on hardware. Layout review does not prove1MSPS/channel.
  https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/spi_master.html
  https://raw.githubusercontent.com/espressif/esp-idf/master/components/esp_driver_spi/src/gpspi/spi_common.c

ISOLATION, POWER PATH AND MECHANICS

- Copper HV graphics do not reduce the previously limiting local isolation gap. Front danger
  artwork extends to approximatelyX124.8 versus the low-voltage plane boundaryX131.1, about6.3mm.
  The previously measured approximately6.19mm DCDC routing remains the limiting local feature.
- Slot and plane setback remain present. Symbols identify the hazardous area; copper under
  solder mask is not a safety certification or a guaranteed high-contrast printed warning.
- PE is continuously routed from J1 to P1 and H1 with no fuse/switch in that route.
  H1 geometry agrees with TE63849-1 (5.08mm pitch,1.4mm holes).
  P1 mounting holes are NPTH with no copper. No new gross current-path/PE connectivity fault found.
  Protective-bond fault-current testing, enclosure bonding/harness and finished-product insulation
  qualification are not established by this file review.
  https://www.te.com/en/product-63849-1.html
